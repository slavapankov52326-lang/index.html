ℹ️ О приложении

Помогатор — это сервис бытовых услуг. Вы называете свою цену, а мастера рядом откликаются на ваш заказ.

Для кого: Для тех, кому нужна помощь по дому (уборка, ремонт, сантехника), и для мастеров, которые хотят зарабатывать.

Подписка для мастеров: Первые 7 дней — бесплатно. Далее подписка «Про» — 490 ₽/мес. Для заказчиков — всё бесплатно.
